### 🗂️ Enterprise Document Management System
**SITIS S.A.S. — Popayán, Colombia** · `Sep 2025 – Present`

`React` `Spring Boot` `Docker` `Nextcloud` `Gitea` `Python` `Bash` `PostgreSQL`

A full-stack document management platform built for multiple business areas (Quality, Finance, HR, Commercial) with real-time collaboration, version control, and audit tracing.

- 🐳 Fully dockerized stack: Nextcloud + Collabora + PostgreSQL + Redis + Gitea + custom services
- 🔄 Automated git sync services that detect file changes in Nextcloud and commit them attributed to the real user, resolved from PostgreSQL activity tables
- 🏠 Migrated version control from GitHub to **self-hosted Gitea**, eliminating storage limits and keeping all document history on local servers
- 📄 Python scripts that walk the directory tree, generate YAML metadata sidecars and consolidated Excel catalogs classified by type, area and status
- 🔍 Real-time audit service monitoring Apache access logs and Nextcloud activity, recording every file view and download with user resolution and event type
- 🌐 React frontend + Spring Boot REST API for document catalog visualization and medical record history queries
